# 形狀王國

小學圖形教育網站：認識正方形、長方形、三角形、圓形、平行四邊形、菱形、梯形與正六邊形的特徵，學會周界與面積，並理解公式「為什麼這樣算」。

本專案由 Grok 匯出。原始儲存庫：https://github.com/petercheung1113/flora-glade-stone-apple

## 在 MacBook 上開始

### 1. 安裝 Node.js

需要 **Node.js 22 或以上**（建議安裝 LTS 版本）。

1. 開啟 https://nodejs.org
2. 下載並安裝 LTS
3. 開啟「終端機」（Terminal），確認版本：

```bash
node -v
```

應顯示 `v22` 或更高。

### 2. 安裝依賴並啟動

在專案資料夾內執行：

```bash
npm install
npm run dev
```

瀏覽器開啟：**http://localhost:8080**

> 注意：開發伺服器埠號是 **8080**，不是常見的 3000。

### 3. 停止伺服器

在執行 `npm run dev` 的終端機視窗按 **Control + C**。

### 4. 可選：正式建置

```bash
npm run build
```

建置成功後可用 `npm run preview` 預覽產物（視專案腳本而定）。

## 功能簡介

- **王國地圖**：八座圖形島，每島五站——認識、周界、面積、實驗、通關
- **動手實驗**：拖曳尺寸，即時看周界與面積變化
- **挑戰廣場**：多組練習題，答完立刻看到解釋
- **進度星星**：完成本地進度會累積星星（存在瀏覽器本機）
